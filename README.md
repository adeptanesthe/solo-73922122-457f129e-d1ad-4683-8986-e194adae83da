# 手工课机位切换 · 切点确认与竖屏 9:16 取景

手工课多机位素材改竖屏：先在网页上**确认机位切点**，把素材拆成镜头，再对每个镜头
在原图内按原高裁出 9:16 竖窗，保证手与工件（逐帧必留框）始终完整留在画面里，
并让裁切轨迹在时间上尽量平滑、画面信息量尽量大。

## 功能

### 切点检测与确认

- 对每对相邻原帧，比较**同位置背景灰度的皮尔逊相关系数**：落在任一帧必留框里的
  像素一律排除，只比背景。
- 有效背景**不足全帧 1/4**，或**任一帧在这些位置灰度恒定**（相关系数无定义）→
  该对帧标为**待核对**，不给相关系数。
- 相关系数低于网页所设**阈值**的相邻帧列为**建议切点**；调阈值只更新建议列表，
  不影响已确认切点，也不触发重新求解。
- 点击候选（建议或待核对）跳到**切点后一帧**；可一键"标为切点"，也可在任意帧
  手动标记/撤销切点，或点已确认切点上的 ✕ 撤销。

### 分镜头取景

- 按已确认切点把素材拆成镜头，每个镜头独立沿用取景规则求解：
  裁切窗高 = 原图高 H，宽 = 9H/16，仅横坐标 x 可变；每帧窗口覆盖全部必留框；
  相邻帧横移 `|Δx| ≤ 8`，连续两次有向横移之差 `|Δxᵢ₊₁ − Δxᵢ| ≤ 2`；
  目标为最大化窗口内横竖相邻像素灰度差绝对值之和（二阶动态规划全局最优）。
- **锁定留在原帧**：锁定/解锁始终按原片帧号记录，拆镜头、改切点都不丢。
- **增量重算**：改切点或锁定只重算受影响的镜头（前端按"素材版本 + 镜头帧范围 +
  范围内锁定"识别未变镜头并保留结果，服务端另有同样的结果缓存），其余镜头照常预览。
- **无解镜头**：显示该镜头在**原片**中首个接不上的帧（全局帧号），并撤下该镜头的
  竖屏预览；其余镜头不受影响。
- **迟到结果保护**：求解请求带素材版本号，素材已变时服务端返回 409；前端再
  逐项核对镜头的"范围 + 锁定"键，素材、镜头帧范围或锁定已变时，迟到的响应不会
  覆盖当前预览。

### 查看与编辑

- 逐帧查看原图 + 必留框 + 裁切窗，右侧实时 9:16 竖屏预览。
- 可**拖动**裁切窗并**锁定/解锁**任一帧；改动锁定后只重算该帧所在镜头，
  前后未锁定帧自动跟着调整。
- 镜头条显示每个镜头的帧范围与求解状态，点击跳到镜头起点（或首个接不上的帧）。

## 必留框 JSON 格式

```json
{
  "frames": [
    [[x0, y0, x1, y1], ...],
    ...
  ]
}
```

- 顶层也接受裸数组（等价于 `frames` 的值）。
- 长度必须等于帧数；每帧可为空数组（该帧无必留框）。
- 框为像素区间 `[x0, x1) × [y0, y1)`，须在画面内。裁切窗高为整帧高，故只有 x 方向影响可行性。
- 上传多帧时按文件名自然序排列（frame_2 在 frame_10 前）。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/upload` | multipart：`frames`（多个 PNG）+ `boxes`（JSON 文件）→ 元信息 + 相邻帧相关统计 |
| POST | `/api/load_sample?name=a\|b\|c\|d` | 载入内置样片 |
| POST | `/api/solve_shots` | body `{"mat": 素材版本, "shots": [{"start","end"}], "locks": {"帧号": x}}` → 逐镜头轨迹或全局 `fail_frame`；`mat` 过期返回 409 |
| GET  | `/api/frame/{i}.png` | 第 i 帧原图 |
| GET  | `/` | 单页应用 |

元信息中的 `pairs` 为长度 n−1 的相邻帧统计：`cut`（切开后新镜头起始帧）、
`bg`/`ratio`（有效背景像素数与占比）、`corr`（相关系数，待核对为 null）、
`review`/`reason`（是否待核对及原因）。

## 已知限制

- 单会话：服务端只保存一份当前工程，多人同时用会互相覆盖（演示定位）。
- 帧数据全在内存：80 帧 × 512×512 灰度约 21MB，可接受。
- 最坏规模（80 帧、x 取值 504 个）单镜头求解约 3 秒；常规规模亚秒。
- 裁切窗垂直位置固定（按原高裁切），只有水平自由度。
- 待核对帧对（有效背景不足或灰度恒定）只提示人工核对，不参与自动建议；
  四段内置样片都不会触发该分支，其正确性由 `tests/test_detect.py` 覆盖。
